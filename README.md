# Lenovo LOQ RGB Installer for Linux

Un script de instalación rápida para habilitar el control del teclado RGB (4 zonas) en laptops **Lenovo LOQ** y **Legion** en distribuciones basadas en Ubuntu/Debian (como Pop!_OS, Linux Mint, etc.).

Este instalador automatiza la descarga y configuración del excelente binario [L5P-Keyboard-RGB](https://github.com/4JX/L5P-Keyboard-RGB) de 4JX, resolviendo los problemas de permisos USB y creando un acceso directo gráfico para que no tengas que usar la terminal.

## Instalación en 1 paso

Abre tu terminal y ejecuta el siguiente comando:

```bash
bash <(curl -s [https://raw.githubusercontent.com/EduardoTapia23/lenovo-loq-rgb-installer/main/install.sh](https://raw.githubusercontent.com/EduardoTapia23/lenovo-loq-rgb-installer/main/install.sh))
